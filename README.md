# 低照度静态照片恢复程序（Low-light Static Photo Restoration）

一套完全本地运行的暗光照片恢复工具：**输入图像与可声明的噪声标定共同决定去噪强度**，
再以**受约束方式提升暗部可见度**，并对模型不适用或饱和的区域给出可靠性提示。
不接入任何云端增强服务；清晰参照图只用于离线测试，运行时从不作为输入。

---

## 1. 图形入口（主要使用方式）

### 启动图形恢复窗口

```bash
# 系统 Python 已带 tkinter 时：
python -m lowlight.gui
# 或安装后：
lowlight-gui
# 或使用启动脚本（用户级 tkinter 解包环境见附录 A）：
./run_gui.sh
```

窗口即“暗光恢复用的图像恢复窗口”，分为左侧控制栏与右侧结果区：

- **打开图像**：选择 PNG/JPG/TIFF/BMP。
- **去噪参数**：强度滑块（单位为方差稳定域的噪声标准差 σ，与图像尺寸无关）、
  NLM / 小波两种边缘保持滤波器。
- **噪声标定（可声明）**：可手动填写信号相关系数 `α`（散粒/泊松项）与固定偏置
  `σ_r`（读出噪声，线性光单位）；**不勾选声明时自动估计**。
- **受约束暗部提升**：阴影目标亮度与增益硬上限；增益随亮度平滑衰减到 1，高光不动。
- **运行恢复 / 导出**：导出原图、恢复图、残差图、可靠性图四份 PNG 与
  `restoration_record.json`（实际参数与中间统计，用于复算）。
- **结果区**：2×2 呈现原图、恢复图像、残差、可靠性图；运行后另弹出“暗部细节”
  对比窗，内容全部来自实际运算数组。
- **异常处理**：读取失败、非法标定、运算异常都显示在窗口下方状态区，不崩溃。

命令行仅用于脚本化批处理（见第 5 节），图形窗口才是主入口。

## 2. 处理原理与流程

全部噪声建模与提亮在**线性光空间**进行（默认输入按 sRGB 解码，可声明已是线性）：

1. **解码** sRGB → 线性 RGB。
2. **噪声模型**：仿射泊松-高斯模型
   `y = α·Poisson(x/α) + N(0, σ_r²)`，即 `Var(y) = α·x + σ_r²`。
   - `α`：**信号相关噪声**（光子散粒噪声，随亮度增长）；
   - `σ_r`：**固定偏置**（读出噪声，与亮度无关）。两项显式区分，不会被混为一个平滑强度。
3. **归一化 Generalized Anscombe 变换（GAT）**：把数据映射到**单位方差**域，
   去噪强度因此以“多少个噪声 σ”表达，对任何亮度、任何图像尺寸语义一致。
4. **边缘保持去噪**：默认 OpenCV 非局部均值（NLM，独立处理 RGB 三通道，不做跨通道混合，
   保留暗部细微色差）；无 OpenCV 时回退到多尺度 Haar 小波软阈值。
5. **精确无偏逆 GAT**：暗处采用有理多项式近似、亮处采用渐近展开，避免朴素代数逆变换
   在暗部引入的偏置。
6. **受约束暗部提升**：对去噪后的信号施加**有上限的增益**（不是先大幅增亮再强平滑）：
   - 增益由亮度分位数决定并做硬封顶（默认 ≤8×），防止噪声被无限放大与静默裁切；
   - 增益随亮度平滑回落到 1，中调、高光与白平衡不被改变；
   - 按通道比例施加，保留通道间的细微颜色差异。
7. **可靠性评估与残差**：逐像素标记并汇总（见第 4 节）。

### 为什么不会“先增亮再强平滑抹掉纹理”

提亮发生在去噪**之后**且增益有界；去噪在单位方差域按物理噪声 σ 进行，
细线等高对比结构被 NLM/小波保留。离线测试中，已曝光参照上的细线对比度保留率约 0.9。

## 3. 未提供标定时的估计流程与适用范围

在左侧不勾选“使用我声明的标定值”即触发自动估计（`lowlight/calibration.py`）：

1. 对每个颜色通道取**固定物理像素**的 8×8 块（步长 4），计算块均值 `m` 与无偏样本方差 `v`。
2. 平坦块满足 `E[v] = α·m + σ_r²`；用块内梯度剔除边缘/纹理块，剔除含饱和像素的块。
3. 对 `(m, v)` 做 **Theil–Sen 稳健回归**：斜率 = `α`（信号相关项），
   截距 = `σ_r²`（固定偏置方差）。三通道结果取中位数。
4. 物理约束：`α ≥ 0`、`σ_r ≥ 0`。斜率为负时退化为恒定噪声模型；
   读出噪声无法测量时回退到保守值 `σ_r ≈ 1/510`（约半个 8 位码值的线性量级），
   并在界面状态区与 JSON 记录中写明警告。

**范围与量纲**：`α`、`σ_r` 均为归一化线性光单位（8 位等效输入映射到 [0,1]）。
估计要求画面中有足够多平坦区域（默认至少 24 个有效块）；纯黑、大面积饱和或高度纹理化
画面会给出警告，此时建议改用手动标定。

### 尺寸不变性

块窗口以**物理像素**固定，参数以**物理线性光单位**表达，从不使用图像宽高的比例。
因此同一噪声水平在不同分辨率下被解释为相同强度。`scripts/evaluate.py` 与
`tests/test_pipeline.py::test_estimation_is_size_invariant` 对 128–384px 做了验证，
各尺寸估计值的散布远小于参数本身量级。

## 4. 可靠性提示

逐像素位标志（`lowlight/reliability.py`），在可靠性图中以颜色叠加，并在 JSON 中汇总占比：

| 标志 | 含义 | 叠加颜色 |
| --- | --- | --- |
| `SATURATED` | 观测达到传感器上限，信息已丢失 | 红 |
| `BLACK_FLOOR` | 信号低于读出噪声底，去噪输出为先验驱动而非数据驱动 | 深灰 |
| `MODEL_BOUND` | 参数超出物理有效范围（如负的散粒系数） | 蓝 |
| `OUT_OF_RANGE` | 非有限或负输入被钳制 | 品红 |
| 可靠 | 以上均不满足 | 白 |

残差视图以中灰表示 0、正负残差向两侧着色并放大显示；线性域残差 RMS/均值写入 JSON。

## 5. 命令行（辅助）

```bash
# 仅估计并打印噪声参数与诊断
python -m lowlight.cli estimate dark.jpg

# 用自动估计恢复
python -m lowlight.cli restore dark.jpg --out-dir runs/01

# 用声明的标定恢复（α、σ_r 为线性光单位）
python -m lowlight.cli restore dark.jpg --alpha 0.004 --sigma-r 0.006 \
    --strength 1.2 --max-gain 8 --out-dir runs/02
```

导出目录包含 `original.png`、`restored.png`、`residual.png`、`reliability.png`
与 `restoration_record.json`。JSON 记录完整配置、噪声来源（calibration/estimate/default）、
每通道 GAT 方差、提升增益与裁切比例、可靠性占比、暗部均值等，可据此复算。

## 6. 离线测试与评估（清晰参照不进入运行时）

测试夹具在 `lowlight/synthetic.py` 中由**已知清晰图**生成不同曝光与噪声观测；
运行流水线只接收噪声观测，清晰图仅在测试/评估侧用于打分。

```bash
# 单元 + 流水线 + GUI 冒烟测试（GUI 用例需 X 显示，容器内用 Xvfb）
python -m pytest tests/ -q

# 多曝光/多噪声扫描、纯黑与单色边界、尺寸不变性，并导出示例四视图
python scripts/evaluate.py --out-dir runs/eval
```

覆盖的检查项：

- **细线保留**：相对“实际曝光参照”的 1px 线对比度保留率；
- **暗部均值**：去噪层暗区相对偏差（与曝光参照同亮度尺度比较）；
- **颜色偏差**：平坦红/绿/蓝色块的逐通道偏置与色度角变化；
- **纯黑区域**：必须被 `BLACK_FLOOR` 标记且恢复后均值仍接近 0，不得“发明”纹理；
- **单色区域**：色相次序保持、不坍缩成灰；
- **饱和区域**：必须被 `SATURATED` 标记；
- **尺寸不变性**：不同分辨率下同噪声得到一致的 `α/σ_r`。

## 7. 模块结构

```
lowlight/
  color.py         sRGB/线性转换、亮度系数
  noise.py         仿射泊松-高斯模型、归一化 GAT 与精确无偏逆变换
  calibration.py   块统计 + Theil–Sen 噪声参数自动估计
  denoise.py       GAT 域 NLM（默认）与 Haar 小波（回退）边缘保持去噪
  lifting.py       有界、平滑回落、按通道保色的暗部提升
  reliability.py   逐像素可靠性标志与叠加图
  pipeline.py      端到端流水线、图像读写、结果导出
  synthetic.py     测试用合成观测生成（运行时不导入）
  metrics.py       细线/暗部/颜色/黑块等评估指标
  cli.py           命令行辅助入口
  gui.py           图形恢复窗口（主入口）
tests/             算法与 GUI 测试
scripts/evaluate.py 离线评估报告
```

## 附录 A：无 root 环境下的 Tkinter / Xvfb 准备

本仓库开发环境无系统级 Tkinter，采用 `apt download` + `dpkg-deb -x` 解包到用户目录
（`python3-tk`、`tk8.6-blt2.5`；无头测试另需 `xvfb` 及 XKB 相关包）。
设置环境变量后即可运行，无需 root：

```bash
export LOWLIGHT_TK_ROOT=$HOME/.local/extracted
export DISPLAY=:99          # Xvfb 提供
./run_gui.sh
```

桌面环境下系统自带 Tkinter 时无需上述变量，直接 `python -m lowlight.gui`。
